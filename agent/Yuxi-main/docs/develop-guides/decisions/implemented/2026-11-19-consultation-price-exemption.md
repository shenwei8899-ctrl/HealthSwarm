# 营养咨询免计费审批

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/health_ai_budget_service.py

后续变更见 [健康 AI 默认关闭计费审批](2026-11-19-health-billing-approval-off.md)。

## 问题

线上营养咨询的价格审批于 2026-11-19 到期，用户无法继续咨询。用户确认取消这项审批。

## 决策

### 实现方案

线上严格模式下，普通营养咨询的就绪检查与模型调用不再依赖价格审批，保留模型配置校验和原有 4096 token 输出上限。API 意图分流和 Worker 的咨询模型调用复用该规则。独立指标解读继续使用其计费用途检查，成员授权与咨询运行回执由原服务维护。

## 替代方案

续签价格仍会产生到期中断。修改全局预算模式会影响指标解读、饮食分析与共用账本。

## 验证

| 验收主张 | 失败面 | 语义 Owner | 直接证据 / 命令 | 负向案例 | 当前结果 |
| --- | --- | --- | --- | --- | --- |
| 咨询无需有效价格仍可调用 | 就绪显示可用但模型前检查拒绝 | 预算与入口就绪服务 | Linux 容器定向单测 93 项，独立 PostgreSQL 集成 26 项，线上合成咨询 | 无效模型和其他用途缺价格仍拒绝 | Passed |
| 保存线上真实回复 | HTTP 接受后 Worker 无最终消息 | 咨询 API、Worker、PostgreSQL | 线上合成会话经分流和咨询回读终态 | 无授权的会话请求返回 404 | Passed |

API 和 Worker 发布后均通过健康检查。用合成账号发送歧义请求，意图模型返回追问且未进入失败回退。发送“早餐怎么省事？”后，正式咨询完成，回读到助手回复和模型用量，未写入审批价格账本。血糖、血脂和血压解读仍报告价格未配置。合成记录已清理。本次验收走线上 API 和 Worker，微信真机未测试。

## 后果

供应商仍按实际用量计费。普通咨询的回复继续在运行记录中保存模型用量。意图分流和记忆处理的直接调用不再通过已审批价格账本记录用量。
