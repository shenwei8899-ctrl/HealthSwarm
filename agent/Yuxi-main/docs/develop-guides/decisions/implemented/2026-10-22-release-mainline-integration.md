# 统一微信主线与配餐知识来源整合

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/health_family_kb_service.py

## 问题

初始三餐生成依赖家庭营养资料的版本化依据，基础配餐师同时支持独立菜谱资料库参考。两类来源具有不同用途与校验范围，发布整合需要同时保留。

## 决策

初始配餐固定业务工具保留 `query_initial_nutrition_knowledge`，使用家庭营养库与可锁定的来源回执。配餐角色的 `query_family_nutrition_knowledge` 使用独立菜谱资料绑定，回执范围为 `recipe_reference`。共用检索实现按角色确定范围并重读当前 PostgreSQL 分片；咨询和指标助手沿用各自的固定绑定。

构图先从服务器工具列表分离菜谱参考工具，再校验原固定业务模式。初始模式包含两个检索工具，其他模式仍只允许自身业务工具与菜谱参考。工具审计、checkpoint、最终输出和消费方继续复核来源、授权及版本，文档内容不能替代批准菜谱、营养计算或规则。

微信身份、本人确认、邀请与有来源的采购使用同一主线。正式构建关闭本机业务密码入口；浏览器 H5 的新用户登录需要单独满足受支持的微信授权方式，不能把本机联调入口开放为正式替代。

每日安排保存整份菜单的精确质量检查 ID，读取、发布和商城回源重新验证当前专业规则、知识库原件、配方、食品和成员来源；失效返回过期或拒绝采购。单餐库存重试保留其他餐的原采购载荷。每日 SKU 的全部审核配料及过敏原必须位于该餐已校验食材需求内，不能用混合包引入额外配料；需要额外配料的商品先重新配餐。

商城确认后的推荐包仍允许核价；来源复验覆盖没有单一 ingredient_id 的显式 SKU 包，并按保存的配料快照检查审核映射和换算。自身预占库存不造成来源失效。首次发送前可以换到安全的可售 SKU；结果不确定时保留原商品、原版本和原幂等键重放。匹配器保持原排序，采购候选分数入库时按百分制保存，避免超出 numeric(8,4)。

已部署的专业原件校验、原件查询及营养准备诊断接口在整合中保留；准备诊断与初始生成都读取发布菜谱分类。缺少批准内容时仍保持不可用，不把资料上传当作专业批准。

结果不确定的采购请求在调整其他餐次后仍保留原请求状态、载荷和幂等键；可售目录省略原 SKU 时，预览使用保存商品快照，缺少快照则读取商城单品真值，保留页面所需的嵌套商品身份；预览显示“确认上次采购结果”，允许用户核对原结果，不声称库存可售。首次发送前有安全替代 SKU 时，预览与发布都允许使用同一需求重新匹配。商城同时复核保存/当前完整配料集合、过敏原与包装，额外未审核成分直接拒绝旧来源。

家庭营养师新增本轮真实食材包查询工具后发布版本为 `2026.10.22.1`，基础配餐师的双知识工具版本同为 `2026.10.22.1`；独立发布版本及内容摘要随运行保存，测试预期显式核对工具集合。

## 替代方案

仅保留其中一种检索会丢失实际营养依据或已发布的菜谱参考能力。把两个知识库合并为通用可编辑绑定会扩大角色范围，因此按用途分别绑定并复用同一检索与版本校验实现。

## 验证

App 整合候选 405 项测试通过。Linux 定向单元测试 197 项、隔离 PostgreSQL 与 TCP HTTP 测试 42 项通过；工程契约与 63 项自检通过。商城实际 PostgreSQL 覆盖干净基线升级、重复执行、已执行迁移校验和拒绝、确认后核价和下单重放，以及撤销食材映射负控。Web 的 lint、893 项测试与构建、App 的 H5 和小程序候选构建通过。个人与家庭初始配餐的真实 API、Worker、SSE、checkpoint 两轮运行及伪造/跨 Run 拒绝的 2 项 E2E 通过，外部模型仅使用合成协议回放。最终完整后端单元 4945 项及 7 项 subtest、采购与发布版本专项 73 项、合成协议回放 72 项通过；同一最终镜像的咨询 FIFO、SSE、checkpoint 与各自输出绑定验收通过。合成回放工具清单显式包含新食材包工具，缺失或额外工具仍拒绝。初始工具协议和两类知识来源分别由相关单元测试及 HTTP 来源失效测试验证。外部模型、正式微信、真机及实际支付需要独立验收。

## 后果

API、Worker、迁移器与商城来源校验按同一候选版本发布。服务器 health schema 从 27 升至 28 前已完成两库备份与隔离恢复校验，Agent 恢复库官方迁移器预演保留 5568 份知识文件、22928 分片及业务记录；正式迁移仍使用停机窗口新备份。健康模型政策、批准规则与菜谱映射缺失时保持明确不可用，不使用示例数据完成正式配置。GitHub 源码交付不等于 H5 或微信平台已发布。
