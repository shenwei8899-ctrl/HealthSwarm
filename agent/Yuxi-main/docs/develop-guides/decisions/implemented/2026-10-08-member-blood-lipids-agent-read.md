# 本人血脂四项实测的受控咨询读取

状态：implemented
类型：feature
Owner：backend/package/yuxi/repositories/health_blood_lipids_repository.py

## 问题

家庭档案已保存完整血脂四项，营养师咨询尚不能读取这些原始事实。四项属于同一测量记录，必须共同保留来源与独立版本；任一项更正、作废、来源停用或权限变化后，旧咨询及派生回答不能继续外发旧事实。

## 决策

### 实现方案

复用当前本人实测的正式家庭分页、服务端本人关联、字段授权、冻结模型处理同意和有效Worker attempt。固定零参数工具get_member_blood_lipids_records读取近30个北京时间自然日最多20条记录，每条保留tc、tg、hdl、ldl、mmol/L、时间、来源、ID和版本；四项完整且有限为正数，保持原值，不发送备注、任意条件文本或更正历史。不补缺失项，不跨记录拼四项，不计算比值或临床分级。

普通HTTP读取不创建模型同意。Agent外呼前持久化专用回执，空结果及未关联也登记依赖；咨询历史、checkpoint与终态发布重读冻结范围。健康Schema19→20增量创建引用表，保留体重、血压和血糖来源及回执。当前实际graph、工具、Skill、角色与同意说明同步装配；完整安全档案与控糖Agent仍独立待做。

## 替代方案

通用家庭测量接口允许查询多成员与额外字段，无法直接承担固定本人模型读取和同Run回执。复制共享测量实现会增加四套失效策略的维护；沿用当前公共测量流程并新增血脂投影与专用回执。把四项拆分读取会丢失同一记录事实与版本关系，采用整条投影。

相关后端 unit 单次399项通过，覆盖四类实测读取、咨询授权与发布、重放协议、注册发现和迁移。新增真实JWT/HTTP/PG 10项、实际Worker E2E 8项共18项通过；实际独立PG迁移2项通过，核对19→20增量升级、三类既有测量及回执逐字段保留、幂等和未来21拒绝。普通HTTP读取不创建模型同意，Agent工具要求冻结同意与有效attempt。来源停用场景只切换合成来源的数据库is_active，真实HTTP读取返回404，PG repository核对旧历史/checkpoint校验返回410；本人来源停用业务接口维持既有拒绝状态。

直接和派生迟到输出两个实际Worker场景通过：回放返回包含旧四项原值的正文，期间只更正LDL，旧正文均未发布。既有档案咨询、体重更正、血压更正和血糖测量条件更正四个实际Worker场景通过；这六项包含上述血脂E2E中的两个重验案例，计数不与18项相加。

独立负控进程删除LDL投影时，原值缺字段和同版本单项变化两个oracle按预期失败；移除历史依赖或关闭checkpoint错误状态、JSON解析、实际投影验证时，七个oracle因未拒绝或未调用授权验证按预期失败。移除部分输出的血脂EXISTS时，跳过仅检查SQL形状的断言，正文丢弃和中断正文清空两个oracle因私有正文残留按预期失败，无依赖的两个案例仍通过。各负控核对变异确实命中及具体调用失败原因；导入、参数化及断言报告适配的早期失败批次不计负控证据。

最终真实Chromium/API/Worker/PG独立场景通过：用户填写tc4.8/tg1.2/hdl1.3/ldl2.6 mmol/L后，只更正LDL为2.7；其余三项、时间与来源保持同一记录，新版本为2。旧每日咨询返回410，新咨询读取当前四项；独立回读两次Run、工具回执摘要及最终回答。最终同意页1280/1024/768/375px与深色、旧咨询失效及版本2回答经截图检查。两组浏览器合成数据、checkpoint、临时凭据和专用预览服务已精确清理。

咨询页面24项相关测试、lint和生产构建，40个变更Python文件Ruff检查与格式检查通过。工程门禁核对104项decision与239页文档，63项门禁单测及文档构建通过；独立审查核对功能、授权、来源、回执、发布、UI及验证原因，未发现剩余阻断。

只交付本人原始血脂描述性读取。多人模型处理同意、专业字段编码及审核规则、营养目标、配餐映射、临床解释与21天计划保持原TODO；合成回放证明实际链路，真实外部模型质量及生产迁移另行验收。

本地默认和隔离合成数据库在完整备份后通过正式migrator升级为健康Schema20，API和Worker恢复健康；生产迁移未执行。体重、血压、血糖与血脂各自保留独立事实与引用，完整营养安全就绪状态维持未完成。

本决定接续[本人实测血糖](2026-10-08-member-blood-glucose-agent-read.md)，复用正式家庭分页及共享测量来源流程；内置Skill版本由[发布源码](https://github.com/shenwei8899-ctrl/HealthSwarm/blob/main/agent/Yuxi-main/backend/package/yuxi/agents/skills/buildin/family-nutritionist/SKILL.md)维护，完整营养师、配餐及控糖角色维持各自部分完成或TODO。
