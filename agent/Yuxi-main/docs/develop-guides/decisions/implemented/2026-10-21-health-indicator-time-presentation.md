# 指标咨询保留记录时区与实际查询范围

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/agents/skills/buildin/family-blood-glucose/SKILL.md

## 问题

真实模型在两天范围的合成血糖记录回顾中，将 UTC 测量时间标为北京时间，并沿用近三十日描述。三个指标 Skill 还写死最多二十条，与显式选择可返回一百条的 repository 契约不一致。消息落库、来源有效与执行成功不能证明这些自然语言表述正确。

## 决策

### 实现方案

血糖、血脂、血压 Skill 明确以工具返回的 `period`、`limit`、`truncated` 表述范围；提及测量时刻时保留 `measured_at` 的完整 ISO 字符串和时区标记。筛选日期的 `Asia/Shanghai` 与记录序列化时区分开说明。三个 Skill 递增版本，运行快照及已有审批、引用校验继续由既有服务维护。

模型可见说明拥有本项修正；业务记录、时间存储、API 字段和授权边界沿用既有契约。基线镜像的四角色记录回顾与修订镜像的血糖复验分别留存真实供应商、HTTP、Worker、SSE 和最终 Message 证据。真实模型验收使用独立合成环境；发布 Skill 修订不启用生产用途政策，也不授权真实用户咨询。

## 替代方案

在记录投影中添加本地时间字段会改变来源哈希与既有依赖校验；当前已存在完整 ISO 时间，先纠正说明。用正则验证全部自然语言日期容易误拒绝测量日期之外的表述，暂不增加宽泛输出拦截。

## 后果

Prompt 修订及有限真实样本不能保证全部自然语言答复正确。修订后的血脂与血压仅有相关单测，真实答复复验未运行。正式质量题集、正式客户端与人工审核仍需独立验收，合成测试批准不构成生产数据处理批准。
