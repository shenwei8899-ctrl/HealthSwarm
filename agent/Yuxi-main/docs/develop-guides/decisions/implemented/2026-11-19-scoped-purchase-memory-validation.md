# 范围采购保留当前记忆限制

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/meal_purchase_source.py

## 问题

采购通过已发布快照和数据库元数据减少展示装配，但快照来源校验不能证明当前忌口仍然适用。生成后新增限制、改版或撤回已使用记忆，都可能使旧来源不再允许采购。专属计划匹配的当前商品也可能包含菜单原谱没有的受限成分。

## 决策

范围采购复用当前档案绑定和记忆校验。已使用记忆发生变化时拒绝旧来源；新增限制参与所选菜谱数据库分片和当前采购商品的成分检查。校验只读取所选菜谱元数据，不调用整日展示装配或下载对象。专属计划的商品筛选合并成员档案与当前记忆限制。

## 替代方案

仅比较保存的来源摘要无法发现新增记忆。恢复整日展示装配会重新引入无关餐次、媒体和对象下载。直接禁用采购会阻断仍满足限制的菜品。所选来源和商品各自校验当前限制保留原有范围读取能力。

## 后果

采购读取增加当前记忆查询。来源失效时用户需重新生成或核对餐单；受限商品不进入采购候选。归档展示仍按保存快照只读，不因此获得采购资格。应用的我的餐单和日期归档链接接入家庭归档客户端，专业计划链接继续保留原审核与采用操作。

## 验证

单元回归覆盖已使用记忆变化拒绝、当前牛肉限制阻止所选菜谱，以及菜单原文无牛肉但商品描述含牛肉时禁止专属采购。页面脚本回归覆盖日期归档、游标分页与隐藏清理，前端全量 1825 项通过。
