# 本人血糖实测的 Agent 受控读取

状态：implemented
类型：feature
Owner：backend/package/yuxi/repositories/health_blood_glucose_repository.py

## 问题

家庭档案已保存独立血糖记录，家庭营养师咨询尚不能读取这些事实。血糖数值必须与测量条件、时间和独立版本共同使用；条件更正、作废及权限变化后，旧咨询与 checkpoint 不能继续外发旧事实。

## 决策

本人营养咨询通过固定工具读取已授权的原始血糖及测量条件。条件、数值、来源与独立记录版本共同组成公开投影和来源摘要；仅更正条件也会使旧咨询失效。

### 实现方案

复用本人独立体重和血压的授权、30 个北京时间自然日冻结范围、最多 20 条稳定排序和摘要校验。血糖投影保留 glucose、mmol/L、condition、测量时间、来源、记录 ID 与版本；仅接受档案服务支持的 fasting、after_meal_2h、random 条件。普通读取接口不创建模型同意；固定成员工具经过当前 Worker attempt 和冻结处理同意后读取并持久化引用回执。回执纳入派生历史及 checkpoint 校验，健康 Schema 增量迁移新增专用回执表，保留既有数据。

家庭营养师内置 Skill、实际工具注册、咨询页面说明和角色状态沿真实装配更新。完整营养安全档案、临床阈值、风险分级、用药、配餐和 21 天控糖不属于本项。

## 替代方案

直接让模型读取通用家庭测量接口会扩大可见字段和成员选择范围，缺少同 Run 引用回执。把血糖放入基础档案版本会把独立测量与档案确认混为同一状态。沿用当前测量读取和专用回执，保留各指标独立失效。

相关后端 unit 单次317项通过，包含血糖读取、发布、重放协议、既有咨询/体重/血压、Skill、发现注册和迁移。新增真实 JWT/HTTP/PG 9项及实际 Worker E2E 8项共17项通过；四组真实 Schema 迁移8项通过，包含血糖18→19与未来20拒绝、既有体重/血压/档案来源及回执保留。普通读取没有创建模型同意，工具执行要求冻结同意与有效 attempt；模型接收的测量条件保持档案原值。

当前健康Schema为20，发布迁移回归覆盖档案、体重、血压、血糖与血脂五组，共10项在隔离真实PostgreSQL通过。旧15/16/17/18夹具先移除各自版本之后的全部来源及引用表，再通过独立to_regclass断言缺表；升级后回读既有事实不变、新表为空且主外键、非空及级联约束正确，并复验幂等和未知未来版本拒绝。恢复原夹具时，4项缺表前置条件均在数据库业务断言失败，证明测试能捕获夹具遗留未来表造成的假升级。18版本升级至当前版本同时核对血糖、血脂引用表约束；上述18→19与未来20拒绝仍是血脂加入前的历史验收范围。

仅在独立测试进程关闭条件合法性守卫时，6项异常条件 oracle 因未抛异常失败；移除公开投影的 condition 时，3项原值 oracle 因缺少条件字段失败。两组负控均断言变异实际命中和具体失败原因。早期夹具异常和未命中变异的批次不作为负控证据。

真实浏览器/API/Worker/PG一个独立场景通过：在未确认的空基础档案下填写5.5 mmol/L、空腹、设备来源版本1；只更正为餐后2小时后版本2，数值、测量时间与来源保持。旧每日入口返回410，旧历史HTTP返回404且结果隐藏；用户明确新建咨询后读取5.5及当前条件。两次工具、独立线程与Run、回执摘要和最终回答分别回读。375px及深色处理同意说明、失效恢复入口、版本2回答经截图检查。此前两个浏览器失败批次不计通过。

既有档案咨询、体重更正和血压更正的实际Worker三个场景通过。咨询页面24项测试、lint和生产构建、31个变更Python文件的Ruff检查与格式检查通过；工程门禁核对103项decision和238页文档，63项门禁单测及文档构建通过。独立源码与UI审查核对授权、同意、来源、历史/checkpoint和发布路径；负控证据问题按实际失败原因修复后复核，无阻断。

## 后果

条件属于必要事实，不可从聊天猜测。公开血糖工具仍仅支持本人；多成员授权和专业规则映射继续独立待做。合成重放证明链路，不代替真实模型与专业质量验收。

健康 Schema 18→19通过正式 migrator 增加专用血糖引用表。本地默认及隔离合成库在备份后完成升级，API和Worker恢复健康；生产数据库迁移未执行。其他指标维持各自稳定投影，血糖独立测量不会提升完整营养安全就绪状态。

范围仅包含本人血糖原值的描述性读取。其他成员代读、专业诊断与安全规则、营养目标、配餐映射及21天控糖分别保留待做状态。处理同意政策版本沿既有管理；完整角色继续部分完成，真实外部模型与专业生产验收未执行。[本人血脂四项](2026-10-08-member-blood-lipids-agent-read.md)接续当前读取装配，内置Skill版本与健康Schema以该决定及实际注册为准。

本决定接续[本人实测血压](2026-10-08-member-blood-pressure-agent-read.md)，复用正式家庭测量分页及共享测量来源流程。
