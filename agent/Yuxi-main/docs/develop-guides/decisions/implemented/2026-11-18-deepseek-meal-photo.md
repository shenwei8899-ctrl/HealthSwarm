# 拍照记餐使用 DeepSeek V4.1 Flash

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/health_ai_budget_service.py

## 问题

2026-11-18，线上拍照记餐的视觉模型价格审批过期，照片上传后无法提交识别。用户确认切换到 `deepseek:deepseek-flash`，并取消该模型在拍照记餐用途的计费审批。

## 决策

### 实现方案

拍照记餐的就绪检查和 Worker 的照片识别调用只对 `deepseek:deepseek-flash` 免除价格与单次费用上界审批。模型快照校验和现有的输出限制仍适用。通用模型预算入口继续核对既有价格规则，包括菜谱补译。体检报告指标提取的独立范围见 [体检报告指标提取使用 DeepSeek V4.1 Flash](2026-11-18-deepseek-report-fields.md)。此前的 [健康 AI 参考预算模式](2026-10-26-health-budget-advisory.md) 继续处理其原有用途。

服务端使用既有的处理方审批及用途同意。切换模型后，提交照片的成员需要确认新处理方。Worker 在外部调用前重新检查授权，成功结果和用量回执在已有任务完成事务中保存，候选进入待确认状态。

## 替代方案

续签旧模型价格会维持原视觉模型。扩展全局参考预算模式会改变其他模型或共用账本规则。限定用途和模型可以满足本次切换且保持其他调用的计费路径。

## 后果

供应商仍按实际使用计费。管理员状态的 `occupied_cny_scope` 标明金额只覆盖已审批价格账本。已完成的识图任务保留供应商用量回执，失败尝试的实际费用按供应商账单核对。
