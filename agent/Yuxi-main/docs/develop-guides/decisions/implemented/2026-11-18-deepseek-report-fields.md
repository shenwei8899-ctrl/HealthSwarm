# 体检报告指标提取使用 DeepSeek V4.1 Flash

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/health_ai_budget_service.py

## 问题

线上报告指标模型的价格失效，阻止体检报告提交识别。用户确认保留 PaddleOCR，将指标提取切到 `deepseek:deepseek-flash`，并免除这一步的计费审批。

## 决策

### 实现方案

报告 Worker 使用 PaddleOCR 逐页识别，应用现有隐私过滤，再把脱敏指标行发送到模型。报告的模型就绪检查与实际字段调用对 DeepSeek V4.1 Flash 免价格预留，保留既有每页 8192 token 的输出上限和模型配置校验。OCR 继续核对实际 PaddleOCR 账户的额度或价格。通用结构化调用使用原预算入口。

报告 API 和 Worker 使用处理方审批、成员授权及报告用途同意。授权后的识别结果通过原文证据校验，生成待确认草稿，并在任务终态事务保存用量。拍照记餐使用相同模型的范围见 [拍照记餐使用 DeepSeek V4.1 Flash](2026-11-18-deepseek-meal-photo.md)。

## 替代方案

续签旧模型价格可以恢复原模型。替换 OCR 需要重新建立原文定位和逐页重试契约。保留原 OCR 组件并切换字段模型符合用户确认的处理范围。

## 后果

DeepSeek 按实际用量计费，管理员金额覆盖已审批价格账本。成功任务保留模型用量，失败调用的费用按供应商账单核对。模型处理方更新后，提交新报告需确认当前的报告用途同意。
