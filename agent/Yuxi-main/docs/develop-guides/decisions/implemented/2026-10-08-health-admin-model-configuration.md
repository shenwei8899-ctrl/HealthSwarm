# 健康服务配置保存全部角色模型

状态：implemented
类型：bug-fix
Owner：web/src/components/health/HealthVisionAdmin.vue

## 问题

健康服务配置接口替换六项模型配置，管理页面只发送报告、饮食和咨询三项。管理员保存已有配置会把配餐、饮食分析和质量复核模型替换为空值。

## 决策

### 实现方案

管理页面明确展示六项服务模型，加载服务端的当前选择并完整发送配置。每项模型可以由管理员清空；清空只影响选中的服务。处理政策与审批仍由管理员明确填写和勾选，加载数据不自动批准云处理。后端完整替换配置契约保持不变。

## 替代方案

改为服务端部分更新会改变现有完整配置与冻结审批契约，而且页面仍无法管理三个角色。页面隐藏并回传三个字段虽能防止意外清空，但无法让管理员查看或修改配置，因此采用六项显式选择。

## 后果

候选模型由服务端提供，页面只负责选择。固定版本、凭据与审批有效性仍在服务端校验；页面验证不替代真实外部模型验收。
