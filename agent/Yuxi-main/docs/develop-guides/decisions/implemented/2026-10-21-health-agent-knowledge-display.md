# 健康 Agent 后台知识库绑定展示

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/health_agent_config_service.py

## 问题

健康角色通过业务服务读取固定知识库，通用编辑表单却显示空的可编辑选择，用户无法判断实际绑定。

## 决策

### 实现方案

Agent 详情接口在既有 Agent 访问校验后，附带只读的 `managed_knowledge` 展示投影。服务复用检索代码的角色与配置解析，repository 查询当前库名称和类型，按知识库读取权限隐藏不可见名称与 ID。固定配置缺失、库不存在或类型不支持时返回明确状态。结构化业务角色说明使用业务数据，普通 Agent 保持通用选择。

编辑表单在知识库位置显示后台管理区域，替换该健康角色的通用选择器。元数据不进入保存载荷，不改变检索范围、成员授权、政策、模型配置或运行工具。

## 替代方案

将后台 ID 复制到 Agent 配置会产生两份可独立修改的事实；前端写死名称无法反映重命名或配置错误。采用按请求读取的展示投影。

## 后果

配置展示不证明知识文件可检索或真实模型质量。正式政策仍暂缓，真实用户咨询关闭；验证不调用模型。
