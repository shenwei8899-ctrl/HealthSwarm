# 咨询配置状态与启用指引

状态：implemented
类型：feature
Owner：web/src/components/health/HealthVisionAdmin.vue

## 问题

管理员在健康服务配置页能够保存模型与处理政策，但缺少咨询当前状态和下一步操作。模型选择、配置审批、成员授权与问答验收容易混为同一个完成状态。

## 决策

### 实现方案

在现有管理员组件中展示服务端 configuration.consultation 的已保存状态、模型与 policy_version，按 reason_code 给出下一步操作。状态仅来自父页面读取的配置；本地修改表单或保存失败均不得变为就绪。保留原有保存接口、审批复选框和七项模型字段，不增加后端配置或自动审批。保存成功后复用父页面已有加载流程回读状态。

提示普通咨询可查询固定家庭知识库做一般科普；资料专业审核与成员数据云处理同意是不同用途边界。配置可用后仍需成员授权、用途同意及真实问答验收，不能展示全链路验收成功。

## 替代方案

只补运维文档不能解决页面上无法定位当前阻塞的问题。新增诊断接口会重复现有 configuration 的事实，故复用已有字段。

## 后果

前端仅显示查询时状态；后端仍在提交、执行和发布时验证当前配置与授权。未知原因保留服务端说明并提示刷新，不能推断可用。生产审批及全链路验收由对应负责人继续完成。
