# 参考配餐的商城顺序与家庭访问

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/reference_meal_plan_service.py

## 问题

参考餐单曾按任务版本改变商城与菜谱的查询顺序。普通家庭咨询和参考配餐也可能要求额外的账号授权或配餐同意。

## 决策

每轮参考配餐先读取商城在售商品，再以本轮的商品筛选菜谱、打开完整原谱核对并保存。就餐人数和搭配要求继续按任务原有规则校验。已保存餐单继续使用其原始来源。

当前家庭内的有效成员身份授予家庭档案查看和家庭普通咨询、参考配餐所需的 AI 使用权限。建档人单独修改账号授权不能改变家庭共享权限。今日餐单、聊天参考配餐和调整参考餐单就餐人直接使用该权限。

## 替代方案

切回旧任务版本会连同人数和搭配规则一起回退。仅移除配餐确认页面会留下后端的独立配餐同意条件。

## 后果

商城目录变化后，重新查询分类商品并打开采用的原谱。家庭成员离开后，服务重新读取时会拒绝家庭档案访问。配餐仍校验所选成员及档案是否就绪。

## 验证

本地通过 349 项相关小程序测试。后端集成用例覆盖商城先查、同家庭成员直接创建参考配餐、跨家庭访问拒绝及成员失效后的访问拒绝。本机 Docker Linux 引擎无法连接，集成用例待运行。
