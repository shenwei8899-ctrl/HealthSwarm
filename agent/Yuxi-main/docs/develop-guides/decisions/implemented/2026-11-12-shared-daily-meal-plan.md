# 每日餐单按家庭共享

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/daily_meal_plan_service.py

## 问题

家庭成员用自己的账号进入今日餐单时，需要读取同一天已发布的菜品，并在同一版本上安排或调整。小程序的轮询与聊天发送同时读取时，发送流程需要得到可用的餐单结果。

## 决策

### 实现方案

每日餐单服务先验证当前家庭成员身份，再按家庭和日期读取当前索引。创建任务、发布餐次和追加菜品共用同一个事务锁与版本。共享入口通过当前索引核对菜谱或正式餐次来源。私人参考结果和任务仍通过原属主权限读取。其他成员只收到运行中的状态及可共享的已发布餐次，餐单响应移除内部菜品回执和他人的健康资料。

迁移按发布时间选择家庭日期下已保存的当前记录，保留其余旧行。共享版本从旧行最大版本递增，切换前的待处理指针清空。源档案或菜谱变化继续由读取校验判定。小程序按会话、家庭和日期合并进行中的查询，保存后的读取获取新的结果。提交或发布时的明确版本冲突随任务结果返回。

## 替代方案

各账号保留各自的当前餐单并互相复制会产生多个可写版本，跨账号并发修改时需要再次决定哪个版本有效。按家庭维护一个当前版本使版本校验覆盖所有家庭成员。

## 后果

家庭成员的餐单读取共享当前索引，任务和交易仍分别核对发起账号。没有进入每日餐单索引的私人参考结果保留在原对话里。迁移选择旧索引中的发布记录，后续读取重验其来源和授权。
