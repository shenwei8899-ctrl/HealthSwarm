# 营养咨询保留历史问答与本轮任务边界

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/health_family_kb_service.py

## 问题

旧轮次使用家庭知识库后，模型输入过滤仅保留用户消息，已回答的问题失去助手答复，连续提问被模型理解为多个待答问题。修复需要保留追问所需语义，并继续执行授权、来源及记忆撤回校验。

## 决策

### 实现方案

咨询授权中间件先对完整消息执行现有记忆与反馈过滤，再精简知识库历史。旧知识库轮次保留用户消息及轮末无工具调用的非空助手答复，移除工具过程；当前轮消息原样进入模型。该投影不改写 checkpoint、审计或公开消息，不将历史模型文本视为已成功发布的业务凭据。无完整答复的旧轮次不补造答复或成功状态。

咨询固定提示词和最终正文阶段明确最新用户消息是本轮任务，历史用于理解追问，最新消息明确要求回顾时可以引用历史。旧引用不替代本 Run 的检索及来源核验。前端、队列、持久化结构和发布权限保持原有契约。

## 替代方案

仅添加提示词会保留缺失答案的上下文；删除整轮历史会破坏指代追问；保留完整工具过程增加旧资料干扰。保留问答并维持独立来源校验满足当前修复范围。
