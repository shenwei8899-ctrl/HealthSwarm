# 今日参考餐单选用可烹饪菜谱

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/reference_meal_composition.py

## 问题

每餐强制覆盖食物组会触发按主食补查，并让单独的白饭占用一道菜、产生采购缺项。

## 决策

新版规则按所选餐次和共用菜道数生成参考菜单。食物组用于组合排序。按原谱菜名及食材识别单独的白饭、杂粮饭和白粥，在检索截断前排除，并在原谱确认、选菜装配和保存时核对。排骨粥和炒饭等完整菜品的原谱食材照常进入商品匹配。

## 替代方案

仅在界面隐藏白饭，会留下已计入道数的白饭及其采购缺口。沿用强制食物组会继续触发补查并拒绝道数已足的菜单。

## 后果

新请求使用新版规则。同一幂等请求使用已绑定版本，既有结果按快照中的原版本校验。检索执行次数、菜谱来源、就餐成员限制和现有采购回执仍由服务端核对。

## 验证

回归用例覆盖白饭原谱和繁简写法、道数已足的三餐、旧版组合校验、选菜装配拦截和完整菜品的大米商品匹配。
