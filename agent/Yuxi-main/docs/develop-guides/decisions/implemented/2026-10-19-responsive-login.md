# 登录跳转与业务初始化解耦

状态：implemented
类型：bug-fix
Owner：web/src/views/LoginView.vue

## 问题

认证成功后仍等待智能体、知识库和工具信息，任一辅助接口缓慢都会使用户停留在登录表单。多个旧会话请求返回 401 时，无条件退出和延迟导航还会中断刚建立的新会话。

## 决策

### 实现方案

密码登录和 OIDC 回调在用户 store 应用服务端会话后，直接替换登录路由。成功提示在导航完成后展示。业务目标由共享路径校验函数约束为本地路径，认证页与默认首页目标进入聊天页；路由权限守卫继续检查角色。

智能体 store 保留共享初始化等待，只等待智能体列表与默认详情。知识库和工具名称映射在后台加载；reset 递增会话版本，使退出后迟到的初始化结果无法回填当前 store。OIDC 使用同一会话写入入口，用户主键取服务端 `user_id`。

基础请求层捕获发起请求的 token，仅在当前 token 相同时处理受保护请求的 401。退出时立即保存原访问路径并导航登录页；已在登录页时保留表单。统一错误处理识别已处理认证错误，避免多个业务层重复弹窗。

## 替代方案

只移除登录页的初始化等待能够提前显示系统框架，但默认聊天仍被名称映射阻塞，迟到 401 仍可能退出新登录。继续等待并增加超时只能缩短停留上限，不能消除认证与辅助资料之间的依赖。

## 后果

认证成功即可进入目标页面；辅助名称在数据返回后补齐。认证失败与账号锁定仍停留表单展示原因。知识库、工具和智能体请求不会因此绕过服务端认证或权限限制。此修复不改变后端账号、业务数据和部署拓扑，直接保留 implemented 记录作为局部故障修复的取舍依据。

## 验证

真实 Vue 表单与内存路由覆盖初始化挂起、返回业务目标、重复提交、错误与锁定及 OIDC 会话。请求边界测试覆盖迟到和并发 401、原路径保留与登录页不重复导航。智能体测试覆盖辅助接口挂起、迟到响应隔离与现有并发选择。发布使用本地构建产物，运行时验证和截图保存在发布证据中。
