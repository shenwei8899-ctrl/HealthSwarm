# 正式客户端家庭档案共享联调

本记录面向客户端和后端维护者。正式源码为 `App/`；用户已于 2026-10-16 明确允许本次修改该目录。`agent/miniapp/` 仍为参考工程，不能替代正式客户端验收。

## 范围与决定

沿用已上线的家庭共享服务，不修改数据库结构或放宽 AI 授权。App 的 API 模式接入当前业务账号登录、家庭选择、共享档案及实测维护；复用原有页面样式。商城会员身份不自动映射健康账号，不迁移本机演示健康资料。微信登录整合接口当前不在主线路由中，使用现有 `/api/auth/token`、`/api/auth/me` 和 `/api/family` 完成真实账号联调，微信实机验收单列。

普通档案共享由当前有效家庭成员关系决定，页面读取服务端 `profile_access` 和可编辑字段；独立 AI 授权到期不得清空普通共享档案。退出、停用、跨家庭和账号切换必须清理旧页面；写入携带版本，409 及未知结果必须重新读取后才能再次提交。不同成员的实测独立保存，缺失值不得补零。

| 主张 | 验证方式 | 当前状态 |
