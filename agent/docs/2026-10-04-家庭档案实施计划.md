# 家庭档案 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在现有 Yuxi 左侧增加家庭档案，并交付带数据库保存和成员授权的管理功能。
**Architecture:** 复用 AppLayout 与 FastAPI，业务 service 拥有权限和事务，repository 拥有查询，PostgreSQL 保存事实。
**Tech Stack:** Vue 3、Ant Design Vue、ECharts、FastAPI、SQLAlchemy、PostgreSQL。
**Spec:** [功能设计](./2026-10-04-家庭档案功能设计.md)。

## Global Constraints

全部文件在 agent/。复用现有主题和认证。本人确认授权，字段及指标逐项受控，管理员不绕过。无 localStorage 健康缓存。保持版本、幂等、未知值和时间语义。

## Review Focus

跨家庭或替换成员 ID 不泄漏数据；授权撤回后读写与聚合均受限；重试不重复且不同幂等输入冲突；迟到请求不写回其他家庭页面；更正保留版本。
