# Yuxi 原功能保留与差异核对

核对日期：2026-10-04。本文保存**上游升级前**的核对快照，回答家庭档案开发是否删除原文件、旧预览为什么缺少原功能，以及升级前版本差异。用户随后确认升级到上游最新版；当前源码与运行结果见 [上游升级交付说明](./2026-10-04-Yuxi上游升级交付说明.md)。以下“当前”均指升级前快照；升级采用上游的目录重组，不沿用本文的升级前文件数量。

## 核对结果

本次开发没有删除仓库初始化版本中的文件：初始化版本共有 **1263** 个 Yuxi 文件，当前均存在，`git ls-files --deleted` 与 `git diff --diff-filter=D --name-only` 均为空。本次修改了 9 个原文件，新增家庭档案实现、测试与文档。

**运行预览存在缺失：我给出的 5178 地址使用了家庭档案专用测试后端。这个后端只装配认证和家庭档案正式路由，并将其他部分查询返回为空；它无法代表完整 Yuxi 产品。该交付方式造成了原功能看起来被删除，这是需要纠正的问题。**

普通账号 受测普通账号 的角色为 `user`。Yuxi 原有权限会隐藏数据总览、部门管理和部分管理设置；该行为已存在于修改前的源码，账号未被自动提升为平台管理员。

## 与上游最新版的差异

上游共有 **1325** 个跟踪文件：其中 **969** 个与当前本地相同、**195** 个同路径内容不同、**161** 个路径当前本地没有。

缺少的 161 个上游路径在本地初始化提交中也全部不存在，因此不能归因于本次家庭档案开发删除。同路径内容差异中，**193** 个在初始化版本中已经与此上游提交不同。本地初始化版本另外保留 **99** 个上游当前没有的路径，包含旧模块位置和文档。

部分差异来自版本演进和文件重组。例如上游 Skills 代码拆入 `services/skills/` 与 `repositories/skill_repository.py`；本地保留 `agents/skills/service.py`、`repository.py`、`remote_install.py`。单独复制上游新增文件不能完成版本升级，需要连同调用方、契约及迁移一起核对。
