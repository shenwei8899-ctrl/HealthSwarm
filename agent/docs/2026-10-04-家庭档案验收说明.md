# 家庭档案交付与验收说明

适用于开发与产品验收。功能接入现有 Yuxi 左侧“家庭档案”，入口 `/family`；范围按已确认的“正式功能：页面、后端保存与授权”交付。全部开发文件位于 `agent/`。

## 功能范围

| 页面 | 已实现能力 |
|---|---|
| 成员档案 | 创建家庭、添加成员、搜索与切换；编辑基础及营养相关资料、本人确认当前版本、查看变更记录、导出当前授权可见档案 |
| 健康指标 | 体重、血压、血糖及血脂四项的手动实测记录；保留单位、测量时间、来源及条件；趋势、期间筛选、记录更正与历史版本 |
| 统计概览 | 当前授权范围内的成员数、档案就绪人数、期间记录量及人数、每日记录趋势、各类指标记录量 |
| 授权管理 | 管理员生成邀请、本人登录认领；成年成员按字段与指标授权，设置用途及期限、随时撤回 |

档案、指标、版本、授权及访问审计保存到 PostgreSQL。管理员访问成员健康详情需要服务端授权校验。历史、导出、指标与统计采用相同权限边界；缺失值保留为未知，趋势不补造实测值。

界面复用现有布局、登录、主题和组件，支持加载、空数据、失败提示与重试。窗口重新聚焦、手动刷新和可见页面定期刷新会重新查询指标及统计，授权过期会清理敏感展示。手机宽度使用现有“折叠侧边栏”操作。

## 运行与迁移

正式环境按 [Yuxi 部署约定](../Yuxi-main/AGENTS.md) 初始化。上游升级后的组合业务 schema 为 10，兼容本地家庭版本 8 和上游版本 9；迁移与本地完整环境的启动命令见 [上游升级交付说明](./2026-10-04-Yuxi上游升级交付说明.md)。以下为使用标准 Compose 配置的部署示例：

```sh
cd agent/Yuxi-main
docker compose run --rm storage-migrator
docker compose up -d api worker web
```

迁移新增家庭域表并保留旧数据，API/Worker 要求运行数据库版本精确匹配。保持既有 `API_KEY_DERIVATION_SECRET` 稳定，邀请派生复用该密钥。上线前仍需按实际环境完成备份和部署验收。

当前本地地址为 `http://127.0.0.1:5178/family`，连接 `server.main` 正式 API 和独立 Worker；`family_preview.py` 仅保留为测试 fixture。已有账号与合成家庭数据保留在本项目独立的持久化 PostgreSQL 中。上方验收表记录家庭功能首次验收，升级后的回归结果以 [上游升级交付说明](./2026-10-04-Yuxi上游升级交付说明.md) 为准。

## 明确边界

- 成年条件根据本人填写的出生日期校验，未包含身份核验与未成年人监护授权。
- 统计描述档案状态和记录行为；医学阈值、健康评分、疾病诊断与专业建议另行实现。
- 图片识别、设备采集、营养计算、专业复核和 Agent 使用档案未纳入本次范围。
- 完整 Compose 的核心服务已在上游升级任务中启动验证。全量后端 integration、模型与 RAG/图谱业务 E2E、生产数据升级及生产部署未验证。
- 本次改动交付在当前工作区；未自动提交、推送或发布。

功能范围依据 [功能设计](./2026-10-04-家庭档案功能设计.md)，代码决定及代价见 [家庭档案工程决策](../Yuxi-main/docs/develop-guides/decisions/implemented/2026-10-04-family-archives.md)。
