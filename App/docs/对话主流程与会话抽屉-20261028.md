# 对话主流程与会话抽屉

## 当前交互

1. 登录并确认本人资料后进入家庭营养师对话页；原有资料、授权、过敏忌口和医嘱校验继续生效。
2. 直接输入、语音或发送照片。普通“推荐几道菜”“安排三餐”等需求先在同一段咨询中连续交流，不自动跳成需要用户提供食谱的结构化任务。
3. 回答涉及饮食安排时，可以继续换菜，或明确选择“整理成今日餐单”。结构化生成、来源校验和保存规则仍由现有服务执行；建议本身不等于已保存餐单、实际饮食记录或已下单。
4. 服务端返回的食材推荐在对应回复下展示，用户选择后进入原有复核与购买流程，不自动下单或支付。
5. 点击“今日餐单”打开独立弹层，查看已保存内容；关闭后回到原对话。其他五个常用入口继续保留。

## 查看和切换对话

- 左上角菜单打开左侧抽屉；显示首条提问作为标题，按今天、昨天及日期分组，支持分页和重试。
- “新对话”先显示空白欢迎页，首次发送时才创建咨询线程。会话中的草稿分别保留，切换不覆盖其他对话。
- 独立咨询可跨日继续；历史每日咨询受服务端既有规则限制，只能查看，使用“新对话继续聊”开始新的咨询。
- 正在提交、回复、准备图片或录音时，不切换会话；提交结果未知时，保留原请求键确认结果，不重复创建或发送。
- 旧每日记录保留；现有独立历史页面继续兼容旧链接。模拟模式也使用独立会话抽屉，并保留旧每日数据。

## 验证边界

会话目录及普通独立咨询使用既有后端接口，没有修改服务器或体验版。组件、模拟接口和浏览器验证不代替真实模型、微信真机、商城支付或生产验收。当前开发环境的真实请求仍需通过微信合法域名配置后才能继续验收。
