# 补充本餐（2026-11-04）

按用户要求维持现有页面结构与配色，在菜品列表后增加一个“补充本餐”。展开后复用拍照、相册和手动填写；每次只能选择一张照片，一张可识别多种食物。

- 本次候选单独核对，不覆盖已加入菜品、不计入合计；加入后重新计算。
- 同名食物必须选择同一份或又吃一份。后者保留独立 item_id 和原始估计来源。
- 待核对时不可保存；份量和营养缺失仍保持未知。取消、上传失败保留原餐，中途刷新恢复待核对内容。
- 当前页面已保存餐可继续补充：读取原记录并 PATCH 同一 ID，固定餐次与时间，使用 expected_version 和幂等键。网络不确定时重放原请求；版本冲突要求重新读取。多人记录先选择成员。
- 沿用已有后端更正接口。新照片估计引用各自 draft_id；原餐照片和原图坐标按项目 ID 保留，新食物不伪造主餐坐标。原来移除的项目保留 excluded 标记。
