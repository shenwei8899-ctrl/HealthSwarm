# 菜品记餐进入拍照记餐

「记一餐」里的「拍照补充」进入已有 `/pages/scan/index`。路由只携带不透明标识；账号和家庭隔离的草稿携带当前菜品、成员、实际份量、餐次和用餐时间。原页隐藏后停止写入，返回时恢复草稿或服务端回读的保存回执。

拍照页沿用蓝紫渐变，先显示「这次来拍：菜名」和拍照入口。沿用现有上传、识别、授权及核对流程。相同食物经明确确认后合并照片证据；名称不同也可明确确认属于原菜。没有吃原菜时可以移除它。原菜已填的实际克数不会成为新增多道食物后的合计重量。

未选择照片就返回时，原表单仍可不拍照保存。已上传或待核对的照片草稿可继续处理。保存只发生在用户确认后，返回原页显示同一保存回执；响应丢失恢复原保存请求。

后端新增可选 `source_context`，以家庭、餐单日期及版本、来源餐次、菜品身份回读并冻结服务端菜名。识别器把它作为提示，仍以照片实际内容为准。实际用餐日期和餐次可以与来源不同；计划重量不进入摄入记录。旧任务指纹保持兼容，无数据库迁移。
