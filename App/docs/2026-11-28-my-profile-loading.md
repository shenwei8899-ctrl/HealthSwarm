# “我的”页面资料加载优化

原页面在隐藏时清空档案、头像和昵称，返回后重新串行恢复登录并读取家庭资料。单次 GET 默认 15 秒，网络失败再重试一次，因此多段串行读取可能长时间停留在加载提示。

现在复用同账号、同家庭、同会话范围内的展示摘要，包括使用方式、成员数量和本人称呼。已有家庭缓存必须来自 API 且匹配当前家庭；仅提取这些展示字段，不在本页另存健康正文。摘要在 60 秒内复用，过期后保留已有显示并后台更新。头像、昵称在返回页面时后台刷新，使设置页的修改及时可见。

页面读取设 20 秒总等待上限。达到上限后停止等待，提供重新读取；迟到结果不再更新当前页面。该上限不等同于取消底层网络请求，也不会自动重放写操作。读取失败保留同身份的展示摘要；账号、家庭变化或明确的 401/403/404/410 拒绝会清除摘要。进入业务页面后仍由现有服务端接口校验权限，展示摘要不授予业务访问权。

页面隐藏不再清空已读显示；挂载和显示事件共享进行中的读取，卸载时清理等待计时器。控制台只记录读取阶段、错误码和耗时，不输出凭据、健康正文或响应内容。

验证：

- 17 项加载专项测试，连同账号、昵称、合作申请入口、手机号登录及微信认证回归，共 85 项通过。
- 最终小程序和 H5 本地构建通过。
- 线上只读检查的近三小时完成记录中，登录恢复、账号资料和家庭档案读取均为 200；检查时数据库没有超过 15 秒的活跃查询及锁等待。日志没有完整请求耗时，不能据此断言所有请求都很快，或还原截图当时的客户端网络情况。
- 仅更新前端；未修改后端服务、数据库记录或权限规则。

微信预览与本地交付包同步结果记录于本次构建回执；正式版发布不在本次操作范围。
