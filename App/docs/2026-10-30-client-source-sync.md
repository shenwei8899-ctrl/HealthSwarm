# 小程序交互与设置

聊天、今日餐单、家庭档案、计划卡组、饮食记录、长期记忆、订单和地址页面共用当前账号与家庭边界。地址页面在商城身份恢复完成后挂载业务内容，加载或失败时仍可返回。家庭档案的编辑浮层保留草稿、版本核对和撤回咨询授权；长期记忆页面只展示当前选定成员，界面不提供成员切换行。

未知提交继续自动读取原请求，用户可通过该消息的红色感叹号确认重试。确认前后都核对账号、会话、请求编号及当前提交状态，重放沿用原请求编号。取消失败后原任务仍在运行时，停止按钮继续可用。专属计划的成员用途授权保留明确勾选与确认，不因卡组展示替代而自动同意。

设置使用账号头像与昵称，不修改家庭成员姓名。产品反馈独立于饮食反馈，客户端逐张上传私有截图并持有上传回执；最终提交编号是重试边界。后端实现与业务 schema 迁移见[产品反馈决定](../../agent/Yuxi-main/docs/develop-guides/decisions/implemented/2026-10-30-settings-product-feedback-avatar.md)。反馈接口需要业务 schema 14，前端上线前须确认匹配后端与迁移已就绪。

少年助手使用已有 WebP 图像。微信上传排除同图 PNG，保留仍用于历史列表的图标。源码提交不代表服务器部署、微信上传或真机验收；验证结果与未执行范围随 PR 提供。
